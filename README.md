# SportPlanner

> **Опублікований сайт:** [Відкрити SportPlanner](https://melnykmyron111-afk.github.io/SportPlanner/)

SportPlanner — календар-планер для створення та відстеження персонального розкладу тренувань. Дані зберігаються локально у браузері, тож обліковий запис не потрібен.

## Можливості

- Місячний календар із навігацією та позначенням запланованих тренувань.
- Створення й редагування тренувань: тип, тривалість і нотатка.
- Позначення тренувань виконаними та видалення із плану.
- Статистика виконаних тренувань, серії днів і прогресу до цілі.
- Автоматичне локальне збереження плану та синхронізація між вкладками.

## Локальний запуск

Потрібен Node.js та npm.

```bash
npm install
npm run dev
```

Щоб створити production-збірку у `dist/`:

```bash
npm run build
```

## Стек

- React 18, TypeScript, Vite 7, Tailwind CSS і Lucide React.

## Тести

Запуск тестів: `npm test`.
