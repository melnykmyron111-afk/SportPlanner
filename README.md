# SportPlanner

Календар-планер тренувань: обирайте дні, позначайте заняття й тримайте власний ритм. Дані зберігаються локально в браузері — обліковий запис не потрібен.

## Можливості

- Місячний календар із перемиканням місяців і позначенням запланованих днів.
- Деталі тренування: тип, тривалість і нотатка.
- Позначка «виконано» та статистика: кількість виконаних, серія днів, прогрес до цілі.
- Сезонний акцент: палітра кнопок, обраного дня й статистики змінюється разом із місяцем календаря.
- Делікатна «паперова» крапкова сітка у фоні секції планера, що підлаштовується під сезонний акцент.
- Автоматичне збереження плану в `localStorage`.
- Синхронізація між відкритими вкладками через подію `storage`.
- Демо-набір для поточного місяця при першому відкритті.
- Запасний екран помилки замість білої сторінки.

## Формат даних

План зберігається під ключем `sportplanner.workouts.v3` як JSON-обʼєкт, де ключ — ISO-дата:

```json
{
  "2026-11-02": { "type": "strength", "minutes": 45, "note": "Ноги", "done": true },
  "2026-11-05": { "type": "cardio", "minutes": 30, "note": "", "done": false }
}
```

- Формат дати — `YYYY-MM-DD`, місяць і день доповнені нулями.
- `type`: `strength` | `cardio` | `stretch` | `run` | `other`.
- `minutes`: 5–240, ціле число.
- `note`: до 120 символів, може бути порожньою.
- `done`: чи виконано тренування (за замовчуванням `false`).
- Ключі відсортовані за хронологією.
- Порожній обʼєкт означає, що користувач прибрав усі тренування; демо-дані повторно не підставляються.
- Некоректні записи під час читання відкидаються, невідомі поля замінюються безпечними значеннями.

### Міграція з v1 та v2

Версія v2 зберігала масив ISO-дат (`["2026-11-02", ...]`), а v1 — масив ключів `YYYY-M-D`, де місяць був **індексом з нуля** (`2025-11-30` означало 30 грудня 2025). Під час першого завантаження:

- масив v2 перетворюється на тренування типу `other` на 30 хв із `done: false`;
- ключі v1 конвертуються в ISO;
- недоторканий демо-набір травня 2025 автоматично переноситься на поточний місяць;
- відредаговані користувачем дані не переносяться й не змінюються — лише конвертуються ключі;
- після першого збереження старі ключі видаляються.

## Тести

Покрито:

- формування ISO-ключів і валідацію дат (включно з високосними роками);
- розбір старих ключів v1 і міграцію;
- довжину місяців і порожні клітинки календаря;
- нормалізацію деталей тренування (тип, тривалість, нотатка, позначка виконання);
- статистику за виконаними тренуваннями та серію днів;
- прогрес до цілі для відображуваного місяця;
- оновлення поточної дати після півночі;
- визначення пори року за місяцем;
- читання, запис, пошкоджені дані та явно порожній план у `localStorage`;
- міграцію v1/v2 → v3;
- синхронізацію значень із події `storage`.
