# SportPlanner

Календар-планер тренувань: обирайте дні, позначайте заняття й тримайте власний ритм. Дані зберігаються локально в браузері — обліковий запис не потрібен.

## Можливості

- Місячний календар із перемиканням місяців і позначенням запланованих днів.
- Додавання та видалення тренування для обраного дня.
- Автоматичне збереження плану в `localStorage`.
- Синхронізація між відкритими вкладками через подію `storage`.
- Демо-набір для поточного місяця при першому відкритті.
- Запасний екран помилки замість білої сторінки.

## Стек

- React 18 + TypeScript
- Vite 7
- Tailwind CSS (лише базовий reset) + власні стилі в `src/index.css`
- Lucide React для іконок
- Vitest + jsdom для тестів

## Структура

```
src/
  App.tsx                     # композиція сторінки та стан вибраного дня
  main.tsx                    # точка входу + ErrorBoundary
  types.ts                    # спільні типи (Notice)
  components/
    Topbar.tsx                # шапка й навігація
    CalendarCard.tsx          # сітка календаря
    ActionCard.tsx            # картка дій для обраного дня
    ErrorBoundary.tsx         # запасний екран при помилці рендера
  hooks/
    useWorkoutDays.ts         # стан плану, збереження, синхронізація вкладок
  lib/
    dates.ts                  # назви місяців, ISO-ключі, календарна математика
    storage.ts                # читання/запис localStorage і міграція v1 → v2
    dates.test.ts
    storage.test.ts
```

## Формат даних

План зберігається під ключем `sportplanner.workouts.v2` як JSON-масив ISO-дат:

```json
["2026-11-02", "2026-11-05", "2026-11-12"]
```

- Формат — `YYYY-MM-DD`, місяць і день доповнені нулями.
- Масив відсортований за хронологією.
- Порожній масив означає, що користувач прибрав усі тренування; демо-дані повторно не підставляються.
- Некоректні записи під час читання відкидаються.

### Міграція з v1

Стара версія зберігала ключі під `sportplanner.workouts.v1` у форматі `YYYY-M-D`, де місяць був **індексом з нуля** (`2025-11-30` означало 30 грудня 2025). Під час першого завантаження такі ключі конвертуються в ISO, після чого старий ключ видаляється.

Недоторканий демо-набір травня 2025 автоматично переноситься на поточний місяць. Відредаговані користувачем дані не переносяться й не змінюються — лише конвертуються ключі.

## Тести

Покрито:

- формування ISO-ключів і валідацію дат (включно з високосними роками);
- розбір старих ключів v1 і міграцію;
- довжину місяців і порожні клітинки календаря;
- читання, запис, пошкоджені дані та явно порожній план у `localStorage`;
- синхронізацію значень із події `storage`.

Запуск: `npm test`.
